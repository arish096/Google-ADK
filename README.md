## 📌 About This Repository

This repository contains my notes, code, experiments, and learning resources from my journey into **Google ADK and AI Agent Development**.

The goal is to understand how modern AI agents work and learn to build applications that can reason, use tools, manage context, follow workflows, and collaborate with other agents.

This is a continuously evolving learning repository. New concepts and implementations will be added as I progress through the course.

---

## 🎯 Learning Goals

- Understand the fundamentals of AI agents and agentic systems
- Learn how LLMs, tools, memory, and feedback loops work together
- Explore single-agent and multi-agent architectures
- Build structured workflows using Google ADK
- Learn tool integration and structured outputs
- Understand sessions, state, memory, and RAG
- Explore MCP and Agent-to-Agent (A2A) communication
- Practice evaluation, debugging, and deployment
- Build practical AI-powered applications
